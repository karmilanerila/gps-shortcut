An entry for the [make.fun bounty "The GPS Swears It Was a Shortcut"](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9?ref=h379tqrk).

`main.py` writes the GPS's own one-line excuse for sending the driver down the wrong road to `/output/entry.txt` — smug, defensive, and blaming the map for a shortcut that ends in a lake.

Run it with:

```sh
python3 main.py
```
